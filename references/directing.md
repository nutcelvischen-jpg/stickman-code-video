# 導演方法 · Directing

目標不是「把字放上畫面」，而是讓一個火柴人**用身體把意思演出來**。以下原則改寫自原 skill 的 B1 標準，換成程式繪製可以執行的版本。

## 1. 從旁白開始

1. 先寫好旁白（或拿到音檔），斷成 4–10 段，**每段一個想法**。
2. 每段長度 = 唸完它的實際時間（中文約每秒 4–5 字）+ 0.3–0.6 秒的停頓。不要為了湊秒數拉長或加快語音。
3. 有音檔時，用實際音檔的時間點對齊字幕與動作；沒有音檔時，依字數估計並在 JSON 註明「估計」。

## 2. 每一鏡的三件事

為每個場景寫一行設計稿：

```
旁白：「其實你花最多時間的，是一再重複的瑣事」
主要動作：坐著狂打字 → 文件越疊越高 → 崩潰癱坐
視覺重點：文件堆 + 紅字「重複的事 做了 100 遍」
```

- **主要動作**只有一個，其餘是配角。
- **視覺重點**：大字（2–8 字）、一個道具、或一張圖，擇一為主。字幕不是標題，不要重複同一句。
- 開場 3 秒內就要有**能引起好奇的畫面變化**（角色出場、大字彈出、物件掉下）。

## 3. 節奏

- 畫面主體**每 2.5 秒內要有進展**：新物件出現、姿勢改變、移動、鏡頭推近。引擎的呼吸微動不算進展。
- 動作在說到那個字的時候發生（例如說「AI」時 AI 圖示彈出），提前 0.1–0.2 秒最自然。
- 動作完成後給 0.3–0.6 秒「定住」讓觀眾看清楚，不要每個東西都在動。
- 不要每一鏡都用「標題 → 圖示 → 底線」同一套進場順序；有時直接給完整畫面。
- 轉場混用：同一話題內用 `cut`/`wipe`，換情緒用 `fade`，揭曉用 `iris`。

## 4. 表演

- 情緒＝表情 + 頭 + 軀幹傾斜 + 手臂 + 站姿一起變。例：沮喪 = `sad` 臉 + `lean 14 head 28` + 手垂下。
- 表情要誇張到手機小畫面也看得懂；同一個表情不要連用整部片。
- 接觸要真實：拿東西用 `attach` 掛在手上；坐下就配椅子；打字手要碰到鍵盤。
- 用 `keys` 做「姿勢 A → 姿勢 B」的情緒轉折（`blend` 0.2 秒 = 突然；0.6 秒 = 慢慢意識到）。
- 多角色時用 `accessory`（帽子、頭髮、眼鏡）或顏色區分，同一角色整部片設計不變。

## 5. 畫面構成

- 16:9：用左／中／右三區排戲，角色與視覺重點分開兩側，留白。9:16：垂直堆疊，大字在上、角色在下。
- 地面 y 約在畫面高度 0.8；底部 15.5% 是字幕帶，人物與重點不要進去。
- 線條為主：填色只用在少數重點（螢光筆效果），強調色全片不超過 3–4 種。
- 內建圖示不夠時，用 `path` 畫具體、看得出是什麼的物件，不要用一個圓圈代替一切。

## 6. 驗收清單（交付前逐項看）

- [ ] 分鏡總覽圖：每格都看得出「這段在講什麼」
- [ ] 沒有元素超出畫面、互相重疊或擋住臉
- [ ] 人物腳底踩在地面上，坐姿有椅子，拿東西手有碰到
- [ ] 每場都有主要動作；沒有超過 2.5 秒的靜止畫面
- [ ] 表情與姿勢有變化，不是整部片同一張臉
- [ ] 字幕單行、不換行、與旁白同步；大字與字幕不是同一句
- [ ] 實際播放一次 MP4（不是只看靜態圖）：節奏、轉場、音量
- [ ] 沒有捏造的數據、引言或產品功能
